# Study CAD CAM blog exercises backup

The Study CAD CAM blog (URL: <https://studycadcam.blogspot.com/>) was shut down/deleted sometime in 2025.

This blog contained many engineering drawings for practicing 2D and 3D CAD software. It's a pity that it just disappeared. So I wrote a script to download most of the articles and images from the blog's archives on the Web Archive project and organized them in this project.

## Downloader

A small script for automatically downloading blog posts and images from the Web Archive.

Generally, you shouldn't need to use it, as most of the content has already been downloaded and organized into the folders below by category.

## Other Info

### Reddit post about 3d cad exercises

There is also a [Reddit post](https://www.reddit.com/r/SolidWorks/comments/cp8kix/comment/mfzpui2/) that saved some of the drawings from this blog.

The content models shared in reddit post are consistent with the `3d-cad-exercises` folder.

The difference is that No.001-996 exercises are provided in **Korean PDF versions**, while the remaining parts are exactly the same.

### Possible new blogs

Possible new website is <https://blog.naver.com/studycadcam>.

This blog has less content compared to the previous English blog, but [this post](https://blog.naver.com/studycadcam/223787725400) states that it and the previous blog belong to the same owner, who chose to actively close other websites due to operational reasons.

As I don't understand Korean, I cannot verify whether the connection between the two is true, so this is for reference only.
